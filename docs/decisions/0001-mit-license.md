# 0001 — License the core under MIT

Date: 2026-10-30. Status: decided.

OpenSalon's core platform is MIT licensed.

MIT is the lowest-friction license there is: one short page, understood
by every developer, no NOTICE file, no patent language to explain to a
salon owner or an indie hacker. Adoption is the strategy — OpenSalon
wins by being installed everywhere, and MIT removes every reason to
hesitate.

Apache-2.0's main advantage, its express patent grant, is not the
bottleneck for salon scheduling software. And neither license prevents
a competitor from forking the code and hosting it, so the license was
never going to be the moat.

The business is protected differently:

- **Trademark, not copyright.** The code is MIT; the OpenSalon name and
  logo stay Interchained marks. See `TRADEMARK.md` at the repo root.
- **The operated service.** Hosting quality, the booking platform,
  support, and trust are what Interchained sells.

Switching licenses later is effectively impossible once outside
contributions land, which is why this was decided before the repo
opened. Contributions are inbound = outbound MIT, no CLA.
